# Legal demo documents

Sample files used in the README screenshots: a lawyer's consultation with a client whose software supplier delivered late.

| File | Content |
|---|---|
| `software_development_agreement.docx` | Fictitious contract with delivery, penalty, termination and jurisdiction clauses |
| `civil_code_selected_articles.pdf` | Unofficial English translation of articles 186, 389, 412, 416, 475 and 927 of the Brazilian Civil Code |
| `client_intake_notes.md` | Fictitious client facts and a penalty estimate |

All names, dates and amounts are invented. The translation is for demonstration only and is not legal advice.

Try it: add the three files in the control panel, start a session with the microphone, and ask questions such as
*"What does the contract say about late delivery?"*, *"Can we claim more than the penalty?"* or *"Can we terminate the contract because of the delay?"*
